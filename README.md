## Run it

```sh
python3 main.py
```

`main.py` is stdlib-only: it copies the finished image to `/output/entry.png`. The image is 768x1008 PNG, under 1 MiB. To redraw the picture from scratch:

```sh
python3 make_news_image.py
```
